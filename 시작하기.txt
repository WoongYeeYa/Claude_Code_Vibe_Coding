============================================================
       Word to HWP 변환 시스템 - 빠른 시작 가이드
============================================================

[1단계] 처음 사용하시는 경우
----------------------------------------
1. "install.bat" 더블클릭
   → Python 의존성 자동 설치

[2단계] 서버 실행
----------------------------------------
방법 1 (추천): "start.bat" 더블클릭
   → 메뉴에서 "2. 서버 시작 + 브라우저 열기" 선택

방법 2 (간단): "start_server.bat" 더블클릭
   → 서버만 실행, 브라우저는 수동으로 열어야 함

[3단계] 웹 애플리케이션 사용
----------------------------------------
브라우저 주소: http://localhost:8000

1. 파일 변환 탭
   - 워드 파일(.docx, .doc) 업로드
   - "HWP로 변환" 버튼 클릭
   - 변환된 파일 다운로드

2. 템플릿 관리 탭
   - 자주 사용하는 양식을 템플릿으로 저장
   - 저장된 템플릿 조회 및 사용

[기타 유용한 파일]
----------------------------------------
- stop_server.bat     : 실행 중인 서버 종료
- open_browser.bat    : 브라우저에서 앱 열기

[문제 해결]
----------------------------------------
Q. 한컴오피스 한글이 설치되어 있지 않다고 나옵니다
A. start.bat → 메뉴 5번 "한글 버전 확인"으로 설치 상태 확인

Q. 서버가 실행되지 않습니다
A. Python이 설치되어 있는지 확인
   cmd에서 "python --version" 실행

Q. 포트 8000이 이미 사용 중입니다
A. stop_server.bat으로 기존 서버 종료 후 재시작
